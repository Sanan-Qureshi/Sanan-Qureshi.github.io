# Muhammad Sanan Qureshi — Personal Website

A responsive, cosmic-themed personal academic website built with plain HTML, CSS, and JavaScript. It is ready to publish with GitHub Pages.

## Files

- `index.html` — website content and structure
- `styles.css` — cosmic visual design and responsive layout
- `script.js` — mobile navigation and current year

## Before publishing

Open `index.html` and replace these placeholders in the Contact section:

- `YOUR_EMAIL@example.com`
- `YOUR_GITHUB_USERNAME`
- `YOUR_LINKEDIN_USERNAME`

You can also add your photograph, CV, publications, Google Scholar profile, and links to project repositories later.

## Publish with GitHub Pages

1. Sign in to GitHub.
2. Create a **new public repository** named exactly `YOUR_GITHUB_USERNAME.github.io` (replace the placeholder with your GitHub username).
3. Upload `index.html`, `styles.css`, `script.js`, and this README to the repository's root (not inside another folder).
4. Open the repository's **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select branch `main` and folder `/ (root)`, then click **Save**.
7. After GitHub finishes publishing, visit `https://YOUR_GITHUB_USERNAME.github.io`.

It can take a few minutes for the first deployment to appear.

## Customisation

Edit the text directly in `index.html`. Change colours and spacing in `styles.css`. No build tools or paid hosting are required.
